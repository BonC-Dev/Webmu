Backups & storage

Browser data can be cleared or evicted. Keep a full backup if you want another copy of your files.

Metadata contains titles and organization only. Full backups include game files and covers. Engine saves are not included.

Existing games are kept. Duplicate content is skipped. Backups are limited to 96 MB.

Controls & support

Click inside the player before using the keyboard. Arrows move, X is A, Z is B, Enter is Start and Shift is Select. The console toolbar has control settings. Flash controls depend on the file.

Exit removes the player and its audio. Webmu does not promise saved game progress. Use the engine's native save downloads when available; library backups do not include them.

Disc images, BIOS files, archives, DS, PlayStation, N64, DOS and arcade sets are not enabled. Only import files you have permission to use. Bundled examples have source and license information.
